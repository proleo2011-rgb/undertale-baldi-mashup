# Undertale × Baldi's Basics

A fan-made crossover project combining Undertale-style exploration and turn-based battles with Baldi's Basics school setting.

## Planned features
- Play as Frisk.
- Explore a school inspired by Baldi's Basics.
- Collect notebooks and meet characters.
- Face Baldi in a final challenge.

## Status
Early development. This repository contains the project plan, not a playable game yet.
